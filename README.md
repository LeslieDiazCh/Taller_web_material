# Gestión académica

Registro de estudiantes con React.

## Cómo ejecutarlo

Se necesita Node.js 20 o superior.

```bash
npm install
npm run dev
```

Abrir en el navegador la dirección que muestra la terminal. Normalmente es http://localhost:5173
